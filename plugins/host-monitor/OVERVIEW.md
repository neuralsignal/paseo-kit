Shows the CPU, memory, disk and network usage of the machine the Paseo daemon runs on, as one line in the sidebar footer.

The line reads like the built-in usage summary: an icon and percentage for CPU, RAM and disk, with a small meter when the sidebar is wide enough, followed by download and upload speed side by side under one icon. The disk figure adds all local disks together. Meters and numbers turn yellow above 70 percent and red above 90 percent; on macOS the RAM color follows the system's memory pressure instead (see below). On a narrow sidebar the network speeds are dropped first, then disk. Press the line for a popover with about three minutes of history for each metric, the usage of each local disk, plus uptime and load average.

The daemon samples the host every two seconds, disks every thirty, and keeps the history in memory. History resets when the plugin reloads or the daemon restarts. Each connected host reports its own numbers.

Percentages below 10 show one decimal, so a nearly idle host reads 0.4% rather than 0%. On Linux, CPU usage comes from `/proc/stat`; I/O wait counts as idle and steal time, which a VPS loses to its hypervisor, counts as busy. Memory uses the available-memory figure from `/proc/meminfo` on Linux, so the page cache is not counted as used. On macOS, RAM follows Activity Monitor's Memory Used: app memory, wired memory and the compressor, read from `vm_stat`. Cached files are left out because macOS frees them as soon as an app needs room; the popover shows them on a separate line. A Mac often runs at high usage with no shortage, so there the RAM color follows the kernel's memory pressure level (`kern.memorystatus_vm_pressure_level`): yellow at warning and red at critical. Sizes use binary units (KiB, MiB, GiB), so a 994.6 GB disk reads 926.3 GiB.

On Linux, network speed combines host interfaces and excludes loopback and common virtual interfaces such as Docker bridges. On macOS, it also excludes disabled links and VPN tunnel interfaces. The rates cover traffic on the selected host interfaces, including local traffic. If the host's network counters are unavailable, the network section is hidden.

On Linux, the disk list includes block-backed filesystems and ZFS, with each device counted once. It excludes network mounts, memory-backed filesystems and read-only images such as snap packages. Disk percentages follow `df` and exclude space reserved for root from the used and free figures. On macOS, disk usage covers the whole APFS container of the root volume, including system, data and VM volumes. On other systems, the plugin shows CPU, RAM and the root disk.

The plugin reads local system counters. On macOS, it runs `/usr/bin/vm_stat` and `/usr/sbin/sysctl -n kern.memorystatus_vm_pressure_level` for memory and `/usr/sbin/netstat -ibn` for network traffic. Every Paseo client connected to the daemon can see the host name and aggregate statistics. Network interface names and addresses stay on the daemon.
